1. Getting started & logging in

Anyone can view everything in the app without an account — fixtures, results, player profiles, league tables. No login needed to browse.

To make changes you need to sign in. There are two account types:

RoleWhat they can do
Admin Full access — create and edit leagues, teams, players, fixtures; manage all squads and scores; manage user accounts.
Captain Restricted access — can manage squads, enter scores, and record match fees for fixtures involving their own team only. Cannot create or delete anything else.

Signing in works the same way for both roles:

  1. Click Sign in in the top-right corner of any page.
  2. Enter your email address and click Send sign-in link.
  3. Open the email from Firebase and click the link — you'll be signed in automatically.
  4. You'll be returned to wherever you were.

No password is required. The sign-in link can only be used once and expires shortly after it's sent.

After signing in, your role is shown in the top-right corner — admins see the Admin nav link, captains see a Captain badge.

To sign out, click Sign out in the top-right corner. Your session expires after 10 minutes of inactivity.

Only one user can be logged in at a time. If someone is already logged in, the sign-in page will show a message with the time remaining on their session. A new login is only possible once that session expires or the current user logs out.

Accounts must be created by an existing admin — see Managing accounts.

2. The dashboard (home page)

The home page gives a quick overview of the club's activity.

Season badges — The S / A / V / W circles next to "Team Tracker" in the top nav (and the matching cards on this page) let you switch between the four season types: Summer, Autumn, Veterans, and Winter. Click one to scope the Teams and Fixtures pages (and the Teams/Fixtures figures and Eligibility grid on the Players page — see below) — plus this dashboard's own stats and fixture feed — to that season (every gender edition — Men's/Women's/Mixed — of the current year's league under that badge, all together). A badge shown greyed out hasn't started yet (no league exists for it). Click the active badge again to clear back to All Seasons and see everything club-wide. Your choice is remembered as you navigate between pages until you change it. This does not affect the Leagues page itself or any Admin pages, which always show everything. Note: a team not yet assigned to a division won't appear when a season is selected — clear back to All Seasons to see it.

Stats row — Shows the number of teams and fixtures recorded (scoped to the selected season, if any).

Last 7 Days — Lists fixtures from the past week with scores. Click any fixture row to open its detail page. If there are more than three, click "Show more" to expand.

Next 7 Days — Shows upcoming fixtures so you know what's coming up.

Click View All to go to the full fixture list.

3. Leagues

Navigate to Leagues from the top nav bar. Click a league name to open its detail page, which shows divisions, teams, and eligibility rules. This page always shows every league — it is not affected by the season badges on the dashboard.

Parent leagues admin only

Every league belongs to a parent league (e.g. "Cleveland Summer League", "Cleveland Autumn League"), viewable from the Parent Leagues page (linked from the top of the Leagues page). A parent league owns the doubles format shared by all its leagues — pairs per round, sets per rubber, games per set, the tie-break threshold, and a Format selector — plus a colour used to badge its leagues. Once any league is created under a parent, that parent's format fields lock (name, colour, and description can still be changed); this stops the format being changed out from under leagues/fixtures that already depend on it. Parent leagues are pre-configured for the four season types (Summer, Autumn, Veterans, Winter) — there is no option to add a further parent league from the app.

The Format selector decides the rubber structure and scoring used when entering results for every league under that parent:

  • Cleveland Summer and Autumn (default) — a fixed number of pairs per side (Doubles Pairs per Round) in a full round-robin: each pair plays every opposition pair exactly once, so pairs-per-round also sets the number of rounds (e.g. 3 pairs plays 3 rounds/9 rubbers for Summer, 2 pairs plays 2 rounds/4 rubbers for Autumn). Each rubber's set count and games-per-set come from the parent league's own setup — e.g. Summer is a single set to 8 games with no decider, while Autumn is 2 sets to 6 games with a 7-point tie-break at 6-6, and a champion's tie-break to 10 points if the sets are shared 1-1. Scoring: 2 points per rubber win, 1 point each side for a tied rubber, plus 4 bonus points to whichever side wins more rubbers (split 2-2 if equal).
  • Cleveland Veterans — a fixed squad of 2 men + 2 women per side, forming Mens Doubles, Womens Doubles, and 2 mixed pairs who play a full round robin against the opposition's 2 mixed pairs (6 rubbers total). Scoring uses the same 2pt/1pt-tie/4-bonus formula as Cleveland Autumn.
  • North-East Winter — the same fixed 2-men + 2-women squad, but 4 fixed rubbers with no rotation: Mens Doubles, Womens Doubles, Mixed Pair 1 v Mixed Pair 1, Mixed Pair 2 v Mixed Pair 2. Every rubber is played to 2 full sets with no deciding 3rd set — a rubber can end 1-1. Scoring is pure set points (1 point per set won, no bonus), so the maximum fixture score is 8.

Creating a league admin only

Fill in the New League form at the bottom of the Leagues page:

FieldWhat it means
League nameChoose a Season (Summer/Autumn/Veterans), a Discipline (Men's/Women's/Mixed Doubles), and enter a Year — the name is built from these automatically, e.g. "Cleveland Mixed Doubles Autumn League 2026". A live preview shows the result as you fill them in. Winter is shown greyed out — feature unavailable.
Season start dateThe Saturday that Round 1 begins — used to compute round labels on fixtures
Catch-up weeksAdd any number of Saturdays with no rounds played (e.g. a midway break) — round numbers skip over them automatically. Leave empty for a league that runs in consecutive rounds throughout, like the Autumn League
Parent leagueChoose an existing parent league (e.g. "Cleveland Summer League") — this sets the doubles format (pairs per round, sets, games) and the rubber structure/scoring format for the league automatically
Early season weeksRounds where the "one fixture per player per week" rule applies
Team tie thresholdFixtures played before a player is locked to a team — counted cumulatively across that team and every higher-ranked team (e.g. 1 fixture for the A team plus 2 for the C team reaches a threshold of 3, locking the player to the C team)
Number of divisionsHow many divisions to create immediately

Other league actions admin only

  • Edit League — update any of the fields above from the league detail page.
  • Parent league — can only be changed on the league's Edit form before the league has any recorded fixtures.
  • Add Division — type a division name and click Add on the league detail page.
  • Add Team — click Add Team on a division's row to create a new team directly in that division. Teams are always created here, scoped to one league's division — never shared between leagues, even if two seasons have a team with the same name (e.g. "Yarm C Men" in the Summer and Autumn leagues are separate teams).
  • Delete League — removes the league and all its fixtures permanently.
4. Teams

Navigate to Teams from the top nav bar.

The Teams page has two views, switched via the toggle at the top: a Team List and a Weekly Allocation view — a week-by-week breakdown of upcoming fixtures where you can reserve players. Switching to Weekly Allocation shows a league dropdown; pick a league to see its allocation (nothing is shown until you choose one, even if only one league is available).

This page respects the season badges — see the dashboard for how to change it. A team not assigned to any division only appears under All Seasons.

Teams are view-only here — to create a team, go to the team's league on the Leagues page and use Add Team on the relevant division. This keeps teams from different league seasons independent, even when they share a name (e.g. "Yarm C Men" playing in both the Summer and Autumn leagues are two separate teams, each with their own roster and fixtures).

Team detail page

Click a team name to see its roster, fixtures, and current captain.

The player roster shows each player's Wins, Losses, and Win % in two figures: the bold number is their record for this team, and the number in brackets is their record across all leagues combined. For example, 3 (10) means 3 rubbers won for this team and 10 rubbers won in total.

The Fixtures list and the bold "for this team" figures respect the season badges — see the dashboard for how to change it. If a team plays across multiple seasons, switch the selector to see that season's fixtures instead of every fixture the team has ever played.

Editing a team requires login

The Edit button (top-right of the team detail page) lets you rename the team and toggle match fees. Both admins and the team's own captain can do this.

Other team actions admin only

  • Add players — use the Add Players dropdown on the team detail page.
  • Remove a player — click the remove icon next to their name.
  • Set captain — click the star icon next to a player. A confirmation prompt will appear before the change is saved; clicking again (and confirming) removes them as captain. Only one captain per team is allowed — assigning a new one replaces the existing captain.
  • Delete team — removes the team and all its fixtures.
5. Players

Navigate to Players from the top nav bar. Two views are available via the toggle buttons at the top right: Players (the default roster table) and Eligibility (the grid described below).

The Players view shows every club member with their gender, membership status, teams, fixtures played, and season ties. Use the filter boxes above each column to search.

The player list itself always shows every club member, regardless of the selected season badge — name, gender, membership status, and team-play interest are club-wide and don't change with the season. Only the Teams and Fixtures figures shown per player are scoped to the selected season badge (see the dashboard for how to change it); under "All Seasons" they show a player's teams/fixtures across every league ever.

Eligibility Grid

Switch to the Eligibility view to see a cross-table of every player (interested in teams) against every team in leagues that have eligibility restrictions configured. Rows are players; columns are teams, grouped by league.

Use the Men / Women filter to show only one gender. Click any team column header to highlight that column.

Each cell shows how many fixtures that player has played for that team, colour-coded by status:

BadgeMeaning
Empty green outlineEligible — no appearances yet
Green numberEligible — N fixtures played (not yet at tie threshold)
Yellow numberTied to this team — threshold reached
Faded strikethrough numberBlocked — tied to a different team ranked the same or lower

The grid only appears when at least one league has a team tie threshold set. Players not marked as "interested in team play" are excluded. Unlike the player list above, the grid is restricted to players on a team in the selected season badge — pick "All Seasons" to see every interested player.

Player detail page

Click a player's name to see their match history, win/loss record, eligibility status per league, and match fee history.

If the player has an LTA number recorded, it appears as a button below their name — click it to copy to clipboard. If the player has a contact telephone recorded, that appears alongside it, but is only visible to admins and captains who manage a team the player belongs to.

Adding a player admin only

Click Add Player on the Players page and fill in:

FieldNotes
First & last nameRequired
GenderM or F
Membership statusActive or Inactive
Interested in team playYes or No — controls whether they appear in squad dropdowns
LTA numberOptional but recommended
Contact telephoneOptional — only visible to admins and captains of the player's teams

If a similar name already exists, the app will warn you before creating a duplicate.

Editing & deactivating admin only

Use the Edit button on a player's detail page to update their details, including Membership Status. There's no delete — instead, use Deactivate to mark a player inactive. Their profile, fixture history, and team memberships are all kept exactly as they are; the player's name just appears faded everywhere, and they can no longer be newly picked for a squad, a rubber, or as captain. Reactivate them any time by editing their Membership Status back to Active.

6. Fixtures

Navigate to Fixtures from the top nav bar. Fixtures are grouped by calendar week (Saturday–Friday). The current week is highlighted and scrolled into view automatically.

Each row shows the date, home vs away team, score (or a stopwatch if unplayed), round label, and league. Under All Seasons, a small coloured letter badge (matching the S/A/V/W season badges) also shows which season type each fixture belongs to. Click either team name to open the fixture from that team's perspective.

Use the Season, League, and Team filter dropdowns at the top to narrow the list. The Season and League filters only appear under All Seasons — once you've picked a season badge in the top nav, the list is already scoped to it.

Adding a fixture admin only

Import — upload a .ics file exported from Google Calendar. The app matches team names automatically (scoped to your team's own league, so an identically-named team from a different season can't be matched by mistake), shows a review screen, and skips duplicates.

Add Fixture — manually enter a date, home team, away team, and league, then click Save Fixture. Picking a league first narrows the team dropdowns to just that league's teams — useful since the same team name (e.g. "Yarm A Men") can exist as an independent team in more than one season. The correct number of rubber slots is created automatically.

Bulk operations admin only

Tick fixture checkboxes (or use Select all), then use Set League to reassign fixtures in bulk, or Delete to remove them all at once.

7. Entering match results

Open a fixture from the Fixtures list or a team page. What the results grid looks like depends on the league's Format (set on its parent league — see section 3).

Cleveland Summer and Autumn leagues (default format: Cleveland Autumn)

The Pairs table shows one row per pair, with one rubber column per opposition pair — the number of pairs (and so rubber columns) comes from the league's own setup, e.g. 3 pairs / 9 rubbers for Summer, 2 pairs / 4 rubbers for Autumn. Each rubber's set shape also comes from the league's setup: Summer is a single set to 8 games with no decider, while Autumn is 2 sets to 6 games with a 7-point tie-break at 6-6, plus a champion's tie-break if the sets split 1-1. For each rubber:

  • Enter your team's score (left) and the opposition score (right) for Set 1 (and Set 2, for leagues that play 2 sets, e.g. Autumn).
  • If a league plays 2 sets and they're shared 1-1, a third row appears automatically for the champion's tie-break (first to 10 points) that decides the rubber.
  • T — marks the rubber as a tie (no score needed).
  • W — marks a walkover. Click once for a Yarm walkover, again to switch to an opposition walkover, again to clear.

Scoring: 2 pts per rubber win · 1 pt each for a tie · 4 bonus pts to the team winning more rubbers

  1. Select players — choose two players per row from the dropdowns. Score boxes are locked until both are selected.
  2. Enter scores — fill in (or mark T/W) every rubber. The Save button activates only when all cells are complete.
  3. Click Save Results. The overall fixture score updates automatically.

Cleveland Veterans and North-East Winter

Instead of a pairs grid, a Squad picker lets you choose 2 mixed pairs (a man and a woman each) — pair 1's man and pair 2's man form Mens Doubles, and pair 1's woman and pair 2's woman form Womens Doubles, so there's no separate player selection for those rubbers. The Rubbers table below lists each fixed rubber by name (e.g. "Mens Doubles", "Mixed 1 v Mixed 2"):

  • Cleveland Veterans — 6 rubbers, one set each, with the same T/W controls and 2pt/1pt-tie/4-bonus scoring as Cleveland Autumn.
  • North-East Winter — 4 rubbers, two sets each (no tie-breaking 3rd set — a rubber can end 1-1). W here is a single per-rubber walkover that forfeits both sets. Scoring is 1 point per set won, with no bonus points.

In a fixture between two of the club's own teams, only the home side's captain enters scores — the away side's view is read-only for scores (they still pick their own squad) to avoid the two captains submitting conflicting numbers.

Editing fixture details captain or admin

Edit (top-right) — change the date, teams, league, or overall score. The Round field defaults to auto (derived from the league's start date); pick a specific round to override it for rearranged matches. Captains can edit fixtures involving their team.

Clearing or deleting admin only

  • Clear (below the table) — resets all scores and clears squad selections.
  • Delete (top-right) — removes the fixture and all results. Player profiles are preserved.
8. Managing squads

A squad is the list of players reserved for a fixture before it's played — useful for planning and flagging eligibility issues in advance.

Squads can be managed from the Teams page (Weekly Allocation view — select a league from the dropdown to see it) or from an individual fixture detail page.

Selecting players captain or admin

In the Squad section on a fixture page, tick the players you want and click Save Squad. Each player shows a status icon:

IconMeaning
✓ GreenTied to this team for the season — all good
⚠ YellowSelecting this player will tie them to this team — they'll be blocked from lower-ranked teams after this
⊘ RedIneligible — already tied to a different team ranked the same or lower

If a tie would be triggered, a confirmation popup explains this before saving.

Eligibility rules

  • Early season weeks — during the first N rounds (set per league), a player can only appear in one fixture per week across all teams.
  • Team tie — a player's fixtures for a team count towards that team and every lower-ranked team. Once the cumulative total for a team and everything above it reaches the threshold, the player is locked to that team's tier (e.g. 1 fixture for the A team plus 2 for the C team reaches a threshold of 3, locking the player to C even though neither team alone hit the threshold). They can still be picked for a higher team, but not a lower one.

A player's current tie status is shown on their individual player page — this League Eligibility section, the summary stats above it, and the team badges next to the player's name only appear once a season badge is selected in the top nav (there's no single "current" league to show under All Seasons). Match History always lists every fixture — filtered to the selected season badge if one is active, or every season with a small coloured letter badge per row under All Seasons.

9. Match fees

If a team has match fees enabled, a Match Fees section appears on the fixture detail page for captains and admins.

Tick a player's checkbox to mark their fee as paid, then click Save Fees. A running count of paid vs outstanding is shown in the section header.

Match fees can be toggled on or off per team via the team's Edit settings.

11. Managing accounts

Account management is available via Admin in the top nav bar (visible to admins only). All user management is on a single User Access page — admins and captains are registered here together.

Adding an admin admin only

  1. Go to Admin → User Access.
  2. Enter the new admin's email address, select Admin as the access level, optionally pick a Linked player, and click Add user.
  3. Tell them to go to /login, enter their email, and click the sign-in link that Firebase emails them.

No password is set — sign-in always uses an emailed link. Any Firebase user not assigned as a captain is treated as an admin.

Linking a player when adding an admin also lets them use the pitchside match-day login (email + last 4 digits of that player's LTA number) — seeing every fixture, not just ones for a captained team. This is optional and only affects the pitchside login; it doesn't change their normal admin access.

Adding a captain admin only

Captain accounts give a team captain access to manage their team's fixtures without full admin privileges.

  1. Make sure the captain has a Player profile in the app and is set as the captain of their team on the team detail page.
  2. Go to Admin → User Access, enter their email, select Captain as the access level, and choose their linked player from the dropdown.
  3. Click Add user. Their Firebase account and captain role are created in one step.
  4. Tell them to go to /login and sign in with their email.

On sign-in, they will have captain-level access. If a captain is linked to a player who captains multiple teams, they can manage fixtures for all of those teams.

Linking or changing a player admin only

Click the button next to any account (including your own) to set, change, or remove its linked player at any time — without changing their role. For a captain this is the player their squad/scores/fee permissions are tied to; for an admin it's optional and only enables the pitchside match-day login.

Removing a user admin only

On the User Access page, click the button next to the account and confirm. The Firebase account is deleted immediately — they will no longer be able to sign in. You cannot delete your own account.

12. Login activity login required

The Activity page (visible in the top nav bar when signed in) shows all sign-in sessions from the last 30 days.

For each session it shows:

  • The email address of the user who signed in
  • Their role at the time of the session (Admin, Captain, or Viewer)
  • When they signed in and when they signed out
  • The total session duration
  • Whether the session ended via an explicit sign-out or timed out due to inactivity

This page is visible to all signed-in users (admins and captains) for transparency and auditing purposes.

13. Pitchside match-day login

A separate, lightweight login lets a captain fill in a scoresheet from their phone while actually at a match — as a memory aid alongside the paper scorecard used to submit results to the league. It does not touch the real fixture data until an admin or captain reviews and confirms it afterwards, and it doesn't affect (or get affected by) who's signed in to the main app.

Logging in at the match

From the normal sign-in page, follow the "Captain at a match?" link, or go straight to /pitchside/login. Enter the email address and the last 4 digits of the LTA number recorded against your player profile — no sign-in link or password needed, and any number of captains can be logged in this way at once, at different venues, independently of whoever (if anyone) is signed in to the main app.

You'll be shown a list of fixtures to choose from, covering today and the next few days (10 by default — an admin can change this window's length at Admin → Settings) — so you can open an upcoming fixture well ahead of time to submit Yarm's pairs in preparation, then come back and add scores once it's actually played.

Admins use this exact same login (also linked to a player profile of your own — ask another admin to set this up via Admin → User Access if you don't have one), but see every fixture in that window rather than only ones for a team you captain, and choose which side you're entering for when both teams are tracked in the app.

Filling in the scoresheet

The form has two steps, shaped by the fixture's league Format (see section 3):

Cleveland Summer and Autumn leagues — matches the standard doubles format (a fixed number of pairs per side, each playing every opposition pair once). Pairs-per-round and set shape come from the league's own setup: Summer plays 3 pairs / 9 rubbers, each a single set to 8 games with no decider; Autumn plays 2 pairs / 4 rubbers, each 2 sets to 6 games with a 7-point tie-break at 6-6 and a champion's tie-break if the sets split 1-1.

  1. Pairs — enter your team's pairs (typed freely, with suggestions limited to players currently on that team's roster) and the opponent's pairs (typed freely, no suggestions). Click Continue to Scores when ready.
  2. Scores — a section per pair, showing that pair's rubbers (one per opposition pair) and the opposition for each. Each rubber's boxes follow the league's own setup: a single Set 1 box for Summer (no decider), or Set 1 and Set 2 for Autumn (2 sets to 6 games), with a champion's tie-break box (first to 10) appearing automatically if Autumn's sets are shared 1-1. Fill in any or all of them, in any order, as results come in. Tap W/O on a rubber to mark it a walkover instead of entering a score — tap again to switch which side won, and again to clear it. Use Back to Pairs to fix a name.

Cleveland Veterans and North-East Winter — no rotation, just a flat list of fixed rubbers:

  1. Squad — enter your team's 2 mixed pairs (man + woman each, same free-text/suggestion behaviour as above, limited to that team's roster) and the opponent's 2 mixed pairs. Click Continue to Scores when ready.
  2. Scores — one row per fixed rubber (e.g. "Mens Doubles", "Mixed Pair 2"), with 1 or 2 sets to fill in depending on the format. Tap W/O to mark the whole rubber a walkover — tap again to switch which side won, and again to clear it.
  • Save Progress — saves what's entered so far. Safe to use repeatedly throughout the match; nothing is written to the real fixture yet.
  • Submit Final — marks the scoresheet as finished and ready for review. You can still make changes and save again afterwards if needed.

Confirming afterwards captain or admin

Once submitted, a banner appears on the fixture's page (visible to admins and captains of either team) linking to a review screen — the normal manual fixture entry form, pre-filled with everything entered pitchside. Check it over, correct anything needed, and save to update the fixture's real rubbers, results, and score — exactly as if it had been typed in directly.

Only an admin can register a brand-new player. If a captain confirms a scoresheet with a name that doesn't match any existing player, saving is blocked with an error asking for the player to be added via Players first — an admin doing the confirm can still add them on the spot as before. Once registered, a player is a club-wide record, available for every team and season from then on. The player name fields on this screen suggest matching names from every club member as you type, so an existing player from a previous season can be found without typing their name exactly right.

This only applies to your own team's names. The opponent's names (no suggestions, typed freely) are never registered as players and never appear on Players — they're kept purely for reference on this confirm screen, since the app only tracks membership for our own club.
